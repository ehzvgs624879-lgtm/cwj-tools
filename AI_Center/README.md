# AI Center

This folder contains AI-related tools for the CWJ Tools project.

## AI Chat

- File: `aichat.py`
- Run: `python AI_Center/aichat.py`
- Requirements: see `requirements.txt`

Notes:
- This chat is a simple rule-based demo. No external API keys are used.
- Inputs are sanitized and a basic per-IP rate limiter is enabled.
